# yorozu デザインガイドライン

yorozu 全体で共通のビジュアル規約。ツールが増えても一貫性を保つための基準です。

## カラー

| 役割 | 名称 | HEX | 用途の目安 |
|------|------|-----|-----------|
| ベースカラー | Base | `#F4F4F4` | 背景・下地。画面の大部分を占める明るいニュートラル |
| プライマリーカラー | Primary | `#0F1B2D` | 文字・主要UI・ロゴなど。濃紺で全体を締める基調色 |
| セカンダリーカラー | Secondary | `#C9A86A` | アクセント。リンク・強調・装飾に用いる差し色（ゴールド系） |
