## デザイン案（検討中）

上記のブランドカラーとは別に、ビジュアルの方向性として以下の 2 案を検討中。**いずれも未確定**で、採用が決まった時点で「カラー」「タイポグラフィ」の各節へ正式に反映する。

> **実装状況**: 画面上で確認するため、**案A を実装に反映済み**（`app/styles/variables/cssVariables.css.ts` / `app/styles/variables/font.css.ts` が起点）。案が変わる場合もこの 2 ファイルの値の差し替えで大部分が切り替わるようにしている。フォントは Google Fonts から読み込んでいるため、将来 COOP/COEP を付与する場合は自前配信への切り替えが必要。

### 案A: ダークテーマ（発光グリーン）

暗い背景に発光グリーンを乗せた、ターミナル / HUD 的なトーン。

#### カラー

| 役割 | 用途 | 値 |
|------|------|-----|
| 背景 | 画面全体の下地 | `#04070A` |
| パネル | カード・パネル面 | `#060B0E` |
| 最暗 | 最も沈ませる面 | `#050809` |
| 主色 | 発光グリーン（基調） | `#5CFFB1` |
| ハイライト | 主色より明るい強調 | `#C8FFE6` |
| グロー | 発光・光彩表現 | `#2BFF9E` |

テキスト:

| 役割 | 値 |
|------|-----|
| 見出し | `#E6FFF3` |
| 本文 | `#8FEFC4` |
| 副文 | `#6FBF9B` |
| ラベル | `#3E8C6C` |
| 減光 | `#2F6B53` |

無効 / LOCKED 状態: `#2A5D49` / `#22503F` / `#1F4536` / `#17342A`（濃度順）

罫線・面:

- 罫線: `rgba(92, 255, 177, 0.14 / 0.22 / 0.28 / 0.35 / 0.4)`
- 面: `rgba(92, 255, 177, 0.02〜0.05)`

#### タイポグラフィ

| 用途 | フォント |
|------|---------|
| 和文・見出し | Zen Kaku Gothic New（400 / 500 / 700 / 900） |
| 英数字・ラベル・数値 | Share Tech Mono |

| 役割 | サイズ | 実装上の定義 |
|------|--------|-------------|
| h1 | 52px（下層ページは 32px） | `fontMaximumBold` / `fontHeading1` |
| 見出し | 20px | `fontHeading2` |
| 本文 | 12.5〜14px | `fontMedium` |
| ラベル | 10〜11.5px | `fontLabel` / `fontLabelLarge` / `fontMono` |

いずれも `app/styles/variables/font.css.ts` に定義。ビューポート幅に応じて `clamp()` で最小値〜最大値の間を可変にしている（例: h1 は 32px 〜 52px）。

`letter-spacing` は当初 0.12〜0.24em を想定していたが、和文が混在すると読みにくくなるため**実装では入れない方針**とした。

### 案B: yorozu-v2（画像テイスト版）

明るいグレー背景にネイビー / ブルーを乗せた、ドキュメント寄りの落ち着いたトーン。

#### カラー

| 役割 | 用途 | 値 |
|------|------|-----|
| 背景 | 画面全体の下地 | `#F5F6F8` |
| カード | カード面 | `#FFFFFF` |
| 補助面 | 補助的な面 | `#F8F9FB` |
| ネイビー | 基調色 | `#16263F` |
| テキスト | 本文 | `#1B2A44` |
| ブルー | アクセント | `#2F5C8F` |
| 淡ブルー | 淡いアクセント面 | `#E8EEF7` |

副文・淡色:

- 副文: `#6B7789` / `#46536B`
- 淡色: `#98A2B3` / `#A8B2C1` / `#B9C4D4`

罫線・角丸:
