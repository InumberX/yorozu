# yorozu デザインガイドライン

yorozu 全体で共通のビジュアル規約。ツールが増えても一貫性を保つための基準です。

## デザインの正

デザインの正は、claude.ai の yorozu アーティファクト（https://claude.ai/artifact/6n1wTqy226vFk4937X44mP ）にある次の 7 ファイルとする。同じアーティファクトにある他のファイル（`-backup-*`、MV 案 `-mv-*`、`yorozu-v2`、`OGP-old` など）は検討の途中のもので、正ではない。

| 画面 | PC | SP |
|------|----|----|
| トップ（YZ10_100） | `yorozu-cyber-net`（1440px） | `yorozu-cyber-net-sp`（375px） |
| 画像変換（YZ20_100） | `yorozu-cyber-net-image`（1440px） | `yorozu-cyber-net-image-sp`（375px） |
| 動画変換（YZ30_100） | `yorozu-cyber-net-video`（1440px） | `yorozu-cyber-net-video-sp`（375px） |
| OGP | `OGP`（1200×630px） | — |

デザインと実装を食い違わせる場合は、その判断をこのガイドラインに書く（例: 下記の `letter-spacing` を入れない方針）。

- ナビの 1 項目めは、デザインでは「トップ」だが、実装では「ホーム」とする。英語版の「Home」とページ情報の名前（`PAGE_INFO`）にそろえるため。

## カラー

ダークテーマ（暗い背景 + 発光グリーン）。デザインの正で使われている主な色:

| 役割 | HEX | 用途の目安 |
|------|-----|-----------|
| 背景 | `#05080B` | 画面全体の下地。ヘッダーは同じ色を 92% の不透明度で敷く |
| 主色 | `#5CFFB1` | 発光グリーン。ロゴ・現在地の下線・ボタン・罫線（透明度違い） |
| ハイライト | `#C8FFE6` | 主色より明るい強調。リンクのホバー・角の装飾 |
| 差し色 | `#FFB454` | アンバー。フォーカスリング・図形のアクセント |
| 最も明るい文字 | `#FFFFFF` | 見出し・ナビの現在地 |
| 本文 | `#8FD9B6` | ナビの通常色など |
| 淡い文字 | `#D9EDE3` | パネル内の文字など |
| 区切り | `#4FA07F` | 言語切り替えの「/」など |

### 実装上の色（`app/styles/variables/css-variables.css.ts`）

実装の色トークンは、デザインの正より前に検討していた「案A」の値を土台にしている。ヘッダーで使う色（`font.white` / `subLight` / `subMedium`、`background.base`）はデザインの正から追加した。**画面全体の背景（実装 `#04070A` / デザイン `#05080B`）や本文色（実装 `#8FEFC4` / デザイン `#8FD9B6`）など、まだデザインの正にそろえていない値がある。** 各ページをデザインに合わせる際にそろえる。

| 役割 | 用途 | 値 |
|------|------|-----|
| 背景 | 画面全体の下地 | `#04070A` |
| パネル | カード・パネル面 | `#060B0E` |
| 最暗 | 最も沈ませる面 | `#050809` |
| 主色 | 発光グリーン（基調） | `#5CFFB1` |
| ハイライト | 主色より明るい強調 | `#C8FFE6` |
| グロー | 発光・光彩表現 | `#2BFF9E` |

テキスト:

| 役割 | 値 |
|------|-----|
| 見出し | `#E6FFF3` |
| 本文 | `#8FEFC4` |
| 副文 | `#6FBF9B` |
| ラベル | `#3E8C6C` |
| 減光 | `#2F6B53` |

無効 / LOCKED 状態: `#2A5D49` / `#22503F` / `#1F4536` / `#17342A`（濃度順）

罫線・面:

- 罫線: `rgba(92, 255, 177, 0.14 / 0.22 / 0.28 / 0.35 / 0.4)`

状態色（成功 / 警告 / エラー）はデザインに指定がないため暫定値（エラー `#FF6B6B`）。

## タイポグラフィ

| 用途 | フォント |
|------|---------|
| 和文・見出し | Zen Kaku Gothic New（400 / 500 / 700 / 900） |
| 英数字・ラベル・数値 | Share Tech Mono |

| 役割 | サイズ | 実装上の定義 |
|------|--------|-------------|
| h1 | 52px（下層ページは 32px） | `fontMaximumBold` / `fontHeading1` |
| 見出し | 20px | `fontHeading2` |
| 本文 | 13〜14px | `fontMedium` |
| 小さめの本文 | 12〜13px | `fontSmall` |
| キャプション | 12px | `fontCaption` |
| ラベル | 10〜12px（大きめ・数値は 12〜14px） | `fontLabel` / `fontLabelLarge` / `fontMono` |

いずれも `app/styles/variables/font.css.ts` に定義。ビューポート幅に応じて `clamp()` で最小値〜最大値の間を可変にしている（例: h1 は 32px 〜 52px）。

CSS に書く数値（px / rem などのサイズ指定）は整数にし、小数点は使わない。文字サイズも整数の px で指定する。`getFontSize` が出力する rem や、`clamp()` で可変にした結果の表示サイズが小数になるのは対象外（書く数値だけを整数にする）。既存の `sup` / `sub` の位置（`-0.5em` / `-0.25em`）と余白の `4.6vw` は例外として残している。

`letter-spacing` は当初 0.12〜0.24em を想定していたが、和文が混在すると読みにくくなるため**実装では入れない方針**とした。
