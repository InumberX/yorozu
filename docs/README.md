# yorozu ドキュメント

yorozu（万）のドキュメント置き場です。各資料へのリンクと概要を以下にまとめます。

## 目次

- [デザインガイドライン](./design-guideline.md) — カラー・タイポグラフィなど、プロダクト横断のビジュアル規約
- [要件定義](./requirements.md) — プロダクトの目的・スコープ・技術構成
- [画面一覧](./screens.md) — 画面（ルート）の一覧とマップ

## ディレクトリ方針

- プロダクト横断のドキュメントは `docs/` 直下に置く。
- ツール個別の詳細（ツールごとの要件・画面）が必要になったら `docs/tools/<name>/` に切り出す。
  - 例: `docs/tools/converter/requirements.md`
- 並び順は番号プレフィックスではなく、この目次で管理する（間への挿入・リナンバーを避けるため）。
- ファイル名・ディレクトリ名は英語/ローマ字、ドキュメントの中身は日本語で記述する。
