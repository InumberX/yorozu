# yorozu 要件定義

## 概要

yorozu（万）は、開発・web制作で「あると嬉しい」便利ツールを集めた Webツールハブ。すべてブラウザ内で完結し、ファイルをサーバーにアップロードせずに動作する。ツールは継続的に追加していく前提で、第一弾は画像・動画のフォーマット変換ツール。

- URL: `yorozu.afterworks.jp`（afterworks のサブドメイン）
- 姉妹プロジェクト: sugidama

## コンセプト

- 「万（よろず）＝あらゆるものが揃う器」。特定機能に縛られず、ツールが増えても破綻しない。
- ブラウザ完結による軽快さとプライバシー（アップロード不要）。

## スコープ

### 第一弾（MVP）

- 画像フォーマット変換: WebP / AVIF
- 動画フォーマット変換: WebM
- すべてクライアントサイド（ブラウザ内）で変換

### 今後の展望

- 開発・web制作向けの各種ツールを追加していく（変換以外）。

## 機能要件（第一弾）

- 画像 / 動画ファイルをブラウザ上で読み込み、指定フォーマットに変換してダウンロードできる。
- 変換はサーバーに送らず端末内で完結する。
- 【今後詳細化】対応する入力形式、品質 / 圧縮設定、一括変換の有無 など

## 非機能要件

- 変換処理でUIをブロックしない（重い処理は Web Worker で実行）。
- 大きいファイルに対するサイズ / 長さのガード、進捗表示。
- 【今後追記】対応ブラウザ、パフォーマンス目標 など

## 技術構成

### 確定事項

- フロントエンド: React Router v7（SPA モード / `ssr: false`）。用途ルートは `prerender` で静的HTML化。
- ホスティング: Cloudflare Workers（静的アセット配信）。
- ルーティング: 用途ごとにページを分ける（例: `/image`, `/video`）。個別の解説ページは持たせない。

### 技術候補（未確定）

- 画像変換エンジン: jSquash（WASM）
- 動画変換エンジン: ffmpeg.wasm
  - シングルスレッド版 / マルチスレッド版は未決定。
  - マルチスレッド版を使う場合、`SharedArrayBuffer` のため COOP/COEP（cross-origin isolation）ヘッダが必要。
- WASM は静的アセットとして同一オリジンから配信し、`_headers` でヘッダを付与。
