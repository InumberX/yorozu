# yorozu 画面一覧

用途ごとにルートを分ける方針。個別の解説ページは持たない。各ルートは固有の meta（title / OGP）を持たせ、ビルド時に `prerender` する。

## 多言語（i18n）

- 日本語（`ja`）／英語（`en`）の2言語。**日本語がデフォルト**。
- URL スキーム: **日本語は接頭辞なし（`/image`）、英語は `/en` 接頭辞（`/en/image`）**。sugidama と同じ `($lang)` オプショナルパラメータ方式。
- `ssr: false` のため言語判定はクライアントサイド。prerender は両ロケール分のパスを列挙する。

## 画面ID（採番規約）

- 接頭辞は **`YZ`**（yorozu）。sugidama の `SG` と同型の書式。
- 形式: `YZ<カテゴリ2桁>_<画面3桁>`（例: `YZ20_100`）。
  - **十の位＝カテゴリ**: `10`=共通/トップ、`20`=画像、`30`=動画（以降ツール追加ごとに `40`, `50`, …）。
  - **下3桁＝カテゴリ内の画面**: `100` 始まり。サブ画面や関連画面は `101`, `102`, … と増やす（sugidama `SG20_101` と同じ運用）。
- 画面IDは `app/config/paths.ts`（`PAGES`）／`app/config/consts.ts`（`PAGE_INFO`）／`app/types/paths.d.ts` で管理する（sugidama 準拠）。

## ルート一覧

| 画面ID | ルート（JA / EN） | 画面 | 概要 | prerender |
|--------|-------------------|------|------|-----------|
| `YZ10_100` | `/` / `/en` | トップ | ツールのショーケース。利用可能なツールが並ぶ入り口。今後ツールが増える前提のレイアウト | ○ |
| `YZ20_100` | `/image` / `/en/image` | 画像変換 | 画像を WebP / AVIF に変換 | ○ |
| `YZ30_100` | `/video` / `/en/video` | 動画変換 | 動画を WebM に変換 | ○ |

- **Not Found（404）**: 専用の `*`（キャッチオール）ルートは設けない。sugidama と同様に **React Router のエラーページ（root の `ErrorBoundary`）** で処理する。

## 各画面メモ

### トップ `YZ10_100`（`/`）
- ツールがショーケース的に並ぶ。ツールが増えても成立するレイアウトにする。
- ツール一覧は `app/config` のツール登録メタから生成する想定（追加はメタ追記で完結）。

### 動画変換 `YZ30_100`（`/video`）
